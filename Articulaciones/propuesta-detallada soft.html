Taller de Software

Conoce a fondo y de manera detallada cada uno de los pilares técnicos y conceptuales que conforman el plan de estudios del Taller de Software en nuestra institución.

1. Lógica de Programación

Es la cimentación indispensable para cualquier desarrollador de software. Este módulo se centra en desarrollar la agilidad mental y el pensamiento computacional para estructurar soluciones analíticas antes de volcar código en un lenguaje específico.

Aspectos clave que se abordan:

  • Diseño y optimización de algoritmos paso a paso.
  • Construcción de diagramas de flujo (DFD) y pseudocódigo estructurado.
  • Manejo riguroso de tipos de datos, variables y constantes.
  • Implementación de operadores aritméticos, lógicos y relacionales.
  • Estructuras de control condicionales (if, else if, switch) y ciclos repetitivos (for, while, do-while).

2. Programación Estructurada

Un paradigma fundamental enfocado en maximizar la legibilidad, calidad y mantenibilidad del software. En lugar de escribir código monolítico o desordenado, se enseña a seccionar los programas lógicamente en bloques más pequeños y manejables.

Aspectos clave que se abordan:

  • Modularización del código mediante funciones y subrutinas independientes.
  • Mecanismos de paso de parámetros (por valor y por referencia).
  • Control de ámbito de variables (locales frente a globales).
  • Prevención de errores de ejecución y buenas prácticas de escritura limpia (Clean Code).

3. Programación Orientada a Objetos (POO)

El estándar adoptado por la industria moderna para modelar software complejo simulando entidades y comportamientos del mundo real. Permite que múltiples desarrolladores trabajen en paralelo sobre componentes modulares reutilizables.

Aspectos clave que se abordan:

  • Abstracción de elementos y modelado de clases e instancias (objetos).
  • Encapsulamiento de datos mediante modificadores de acceso (público, privado, protegido).
  • Herencia para extender funcionalidades y evitar la duplicación de código.
  • Polimorfismo para invocar métodos de forma genérica adaptándose a cada objeto.

4. Arquitectura de Computadores

Conecta el mundo del software con el hardware subyacente. Comprender cómo operan físicamente los equipos informáticos dota al estudiante de la capacidad de escribir programas mucho más eficientes en consumo de recursos, memoria y velocidad de procesamiento.

Aspectos clave que se abordan:

  • Modelo estructural de Von Neumann y componentes internos de un computador.
  • Funcionamiento de la CPU, unidad aritmético-lógica (ALU) y registros.
  • Jerarquía y gestión de la memoria (memoria principal RAM, caché y registros).
  • Ciclo de instrucción, buses de sistema y procesos de compilación o interpretación del código.

5. Diseño Web

Especializado en la creación y maquetación de interfaces gráficas de usuario atractivas, funcionales y orientadas a la experiencia del usuario (UX/UI), asegurando que el producto digital sea accesible desde cualquier dispositivo.

Aspectos clave que se abordan:

  • Estructuración semántica y moderna de documentos con HTML5.
  • Estilos avanzados, tipografías y efectos visuales con CSS3.
  • Diseño responsivo y adaptativo mediante Flexbox y CSS Grid.
  • Integración y personalización de interfaces ágiles utilizando el framework Bootstrap 5.

6. Lenguajes de Programación

Inmersión profunda en las tecnologías de programación más demandadas y vigentes en el mercado laboral global, abarcando tanto el desarrollo del lado del cliente (Frontend) como del servidor (Backend).

Aspectos clave que se abordan:

  • JavaScript nativo para dotar de dinamismo e interactividad a las páginas web.
  • PHP para la construcción de lógica del servidor y procesamiento de formularios.
  • Java como lenguaje robusto para el desarrollo de sistemas de alta escala.
  • Python aplicado a la automatización y análisis general de datos.

7. Práctica Profesional

Fase de consolidación en la que los estudiantes enfrentan requerimientos y retos reales propios del sector productivo, simulando entornos laborales profesionales y aplicando todos los conocimientos teóricos en proyectos tangibles.

Aspectos clave que se abordan:

  • Análisis y levantamiento de requerimientos funcionales con usuarios reales.
  • Desarrollo integral de proyectos institucionales (como aplicaciones web con códigos QR, sistemas de gestión, etc.).
  • Fases de pruebas de software (Testing), detección de errores y depuración.
  • Documentación técnica y defensa de propuestas ante un comité evaluador.

8. Metodologías Ágiles

Marcos de trabajo modernos que transforman la forma en que los equipos de desarrollo organizan sus tareas, fomentando la adaptabilidad ante los cambios, la comunicación constante y las entregas de valor frecuentes.

Aspectos clave que se abordan:

  • Filosofía y principios del Manifiesto Ágil.
  • Marco de trabajo Scrum (roles, ceremonias como Sprints y Daily meetings, y artefactos).
  • Uso de tableros visuales Kanban para el seguimiento del flujo de trabajo diario.
  • Control de versiones y colaboración grupal en proyectos de desarrollo.

9. Bases de Datos

Pilar fundamental para lograr la persistencia, almacenamiento estructurado y consulta segura de la información en cualquier sistema informático moderno.

Aspectos clave que se abordan:

  • Modelado conceptual y diseño de bases de datos relacionales mediante diagramas Entidad-Relación.
  • Proceso de normalización de tablas para evitar redundancias y asegurar la integridad de los datos.
  • Lenguaje de consulta estructurado (SQL) aplicando sentencias DDL y DML (SELECT, INSERT, UPDATE, DELETE).
  • Conexión e integración de bases de datos MySQL con plataformas web desarrolladas en PHP mediante sentencias preparadas.

10. Perfil del Egresado

El Técnico en Programación de software estará en capacidad de desarrollar aplicaciones o productos informáticos (software), así como también estará capacitado en análisis, diseño, producción y verificación de aplicaciones y productos informáticos integrando técnicas y conocimientos tecnológicos específicos.

De igual manera, desarrolla e implementa aplicativos de software para entornos Windows o entornos Web sobre diferentes plataformas y lenguajes de programación.
